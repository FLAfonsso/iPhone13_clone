# iPhone 13 Pro — Clone

Projeto de front-end que recria visualmente uma página de apresentação do iPhone 13 Pro, inspirado no estilo da página da Apple. A interface apresenta informações do produto, uma seção com descrição detalhada e um seletor interativo que permite alternar entre diferentes cores do aparelho.

## Funcionalidades

- **Página de apresentação:** exibe o título, uma breve descrição e o preço ilustrativo do iPhone 13 Pro.
- **Seletor de cores interativo:** permite escolher entre Verde-alpino, Prateado, Dourado, Grafite e Azul-Sierra.
- **Troca dinâmica de imagens:** atualiza a imagem do aparelho de acordo com a cor selecionada.
- **Indicação visual da seleção:** destaca a cor ativa na interface.
- **Transição entre imagens:** aplica uma mudança de opacidade durante a troca da imagem.
- **Descrição detalhada:** apresenta informações ilustrativas sobre o design e os recursos do aparelho.
- **Layout responsivo:** adapta elementos da página para telas menores com media queries para tablet e dispositivos móveis.
- **Navegação visual:** inclui cabeçalho com links inspirados na navegação da Apple.

## Tecnologias utilizadas

- **HTML5:** estrutura semântica da página.
- **CSS3:** estilização, layout com Flexbox, transições e responsividade com media queries.
- **JavaScript:** manipulação do DOM, eventos de clique, alteração de atributos e controle da cor selecionada.

## Como executar o projeto

O projeto utiliza HTML, CSS e JavaScript puros, sem necessidade de instalar dependências.

1. Clone o repositório:

   ```bash
   git clone https://github.com/FLAfonsso/iPhone13_clone.git
   ```

2. Acesse a pasta:

   ```bash
   cd iPhone13_clone
   ```

3. Abra o arquivo `index.html` no navegador.

   Se preferir, utilize a extensão **Live Server** no Visual Studio Code para executar a página em um servidor local.

## Como utilizar

1. Abra a página no navegador.
2. Visualize a apresentação do iPhone 13 Pro.
3. Clique em uma das opções de cor abaixo da imagem do aparelho.
4. A imagem será atualizada de acordo com a cor selecionada, e a opção ativa ficará destacada.
5. Role a página para consultar a seção de descrição detalhada.

## Objetivo do projeto

Este projeto foi desenvolvido para praticar fundamentos de desenvolvimento front-end, incluindo estruturação com HTML, estilização responsiva com CSS e interatividade com JavaScript. O seletor de cores permite exercitar eventos, seleção de elementos, manipulação de classes e atualização dinâmica de imagens.
